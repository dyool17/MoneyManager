# App language: Spanish and English

Objective: one setting switches every screen of the desktop app between Spanish and English. Branch `main` (user: "directo a main"). Contract in `app/src/i18n/index.ts` (commit a3ba740). Tests: Vitest; `vue-tsc --noEmit`.

## Specs

- S1. "agrega opcion para cambiar idioma principal de todo, espaniol e ingles". The setting lives in Settings → Appearance ("Language · Idioma"), is remembered on this computer (`mm.locale`), and defaults to Spanish when the system language is Spanish.
- S2. "de todo": every user-visible text in every screen, dialog, chart label, empty state, error, button, aria-label, title and Help text follows the setting. Money and dates follow it too (`domain/format.ts` already uses `intlLocale()`). Text generated in `domain/` and shown on screen (opportunity titles/details, health score part labels, budget/pace states, insight descriptions) follows it as well.
- S3. The assistant answers in the chosen language when the user's language is unclear, and the brief is written in it (done in a3ba740). Prompts and the report context sent to the assistant stay in English (model-facing).
- S4. "no mutes mi info de mi cel": no write to the phone during this work; only reads.

## Contract (do not change its API)

- `import { t } from '../i18n'` (path relative to the file). `t('English source text', { n: 3 })` returns the Spanish catalog entry when Spanish is chosen, else the English source; `{name}` placeholders are filled from params. Missing entries fall back to English.
- Spanish catalogs: one file per area in `app/src/i18n/es/<area>.ts`, `export default { 'English source': 'Traducción', ... } satisfies Record<string, string>`. They are merged automatically (`import.meta.glob`). Keys must be the exact English literal passed to `t()`.
- Guard: `app/src/i18n/i18n.test.ts` fails when any `t('literal')` lacks a Spanish entry. Template literals with `${}` are skipped by the guard, so use `t('… {n} …', { n })` placeholders instead of interpolating inside the key.
- Reactivity: `t()` reads the reactive `locale`, so call it in templates or `computed`, not once at module/setup top level into a plain constant (move such constant arrays into `computed` or call `t()` where rendered).
- `t` can be shadowed by template `v-for="t in …"`; rename such loop variables.
- Spanish style: neutral/professional Spanish (no voseo), "tú" form, short UI wording; keep "Money Manager", "PC Manager", ".mmbak", currency codes and product names untranslated.
